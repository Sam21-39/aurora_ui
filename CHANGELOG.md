## 1.0.0

- Initial release of `aurora_ui`.
- Added semantic material model (`AuroraMaterial`).
- Added platform-adaptive render strategies.
- Added core primitives (`AuroraContainer`, `AuroraText`, `AuroraIcon`).
- Added v1 component set (card, button, nav bar, tab bar, sheet, alert, menu,
  search bar, text field, segmented control).
- Added iOS native `UIVisualEffectView` platform view registration.
- Added example app and baseline tests.
